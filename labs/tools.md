# Tools — AI Agents with Gemini Spark (C1259)

**Course Code:** C1259  |  **Version v1.0 · 27 July 2026**

Everything in this course runs in the browser on a standard Google Workspace account.
There is nothing to install.

## Accounts and access

- A **Google account** with Google Workspace access.
- **Gemini Spark** enabled on that account (the trainer confirms access at the start of Day 1).
- A current **Chrome** or **Edge** browser, signed in to the correct account.

## Workspace apps used

| App | Used for |
|---|---|
| **Gemini / Spark** | Instructing, running, reviewing and scheduling your agents |
| **Gmail** | Inbox summaries, reply drafting, lead intake |
| **Google Calendar** | Meeting prep, planning and scheduled events |
| **Google Drive** | Organising files and storing your assistant's outputs |
| **Google Docs** | Generated documents, briefs and digests |
| **Google Sheets** | Structured records — leads, expenses, trackers |
| **Google Slides** | Draft presentation decks |

## Sample data

A **Brightwave Studio** sample scenario (a small creative agency) is supplied for any lab so
that learners who prefer not to use their own inbox or files can still complete every step.

## Safety

- Keep **approvals ON** so nothing is sent, shared or deleted without your review.
- Never paste real passwords, API keys or confidential personal data into an agent instruction —
  use placeholders such as `<API_KEY>` and keep the real value in a secure store, never in a prompt.
- Use only accounts and data you are authorised to use.
