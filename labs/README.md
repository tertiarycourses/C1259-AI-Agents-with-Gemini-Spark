# Labs — AI Agents with Gemini Spark (C1259)

**Course Code:** C1259  |  **Version v1.0 · 27 July 2026**

All 12 labs build one connected **AI operations assistant** for the fictional Brightwave Studio, which you begin in Lab 1 and consolidate in Lab 12. Wherever possible, use your own Google Workspace; a Brightwave sample scenario is provided for anyone who prefers not to use real data. There is **no assessment** — each lab verifies itself with a 'Test it' step.
